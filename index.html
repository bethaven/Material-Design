Manual de Diseño de Google (Material Design)

Guía técnica de componentes y sus reglas visuales.

1. Acción Primaria (FAB)

Indica la función más importante de una pantalla. Debe usar una sombra profunda para resaltar su jerarquía sobre otros elementos.

Estructura HTML:
<button class="boton-fab">+</button>

Estilos CSS:
.boton-fab {
  background-color: #D0BCFF;
  border-radius: 16px;
  box-shadow: 0 8px 12px #00000033;
}

2. Superficies Contenedoras

Indica una agrupación de información. El borde suave ayuda al ojo a identificar que todo el contenido interior pertenece al mismo grupo.

Título

Estructura HTML:
<div class="tarjeta-m3">...</div>

Estilos CSS:
.tarjeta-m3 {
  background-color: #FFFBFE;
  border: 1px solid #CAC4D0;
  border-radius: 12px;
}

3. Campo de Escritura

Indica interactividad. La línea inferior resaltada le confirma al usuario dónde debe fijar su atención para ingresar texto.

Estructura HTML:
<input type="text">

Estilos CSS:
input {
  border-bottom: 2px solid #6750A4;
  background-color: #F4F4F4;
}

4. Selección Rápida (Chips)

Indica opciones filtrables. Su forma de cápsula facilita que el usuario entienda que son elementos individuales y clicables.

Activo 
Estructura HTML:
<span class="chip-activo">Activo</span>

Estilos CSS:
.chip-activo {
  background-color: #EADDFF;
  border-radius: 8px;
  color: #21005D;
}

5. Estado del Sistema

Indica si una función está encendida o apagada. El uso del color de énfasis confirma visualmente que el proceso está activo.

Estructura HTML:
<div class="switch-fondo">...</div>

Estilos CSS:
.switch-fondo {
  background-color: #6750A4;
  border-radius: 100px;
}

6. Tiempo de Espera

Indica que el sistema está trabajando. La barra visual reduce la ansiedad del usuario al mostrar que hay actividad en segundo plano.

Estructura HTML:
<div class="barra-base">...</div>

Estilos CSS:
.barra-color {
  background-color: #6750A4;
  height: 4px;
}
